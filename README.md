# Chat App

Privacy-first real-time chat with an integrated P2P wallet.

| Folder      | What                                                        |
| ----------- | ----------------------------------------------------------- |
| `web/`      | Next.js 16 (App Router), Tailwind v4, Motion, Supabase SSR   |
| `mobile/`   | Flutter app (`supabase_flutter`)                             |
| `supabase/` | CLI config, SQL migrations, edge functions                   |

Supabase CLI commands run from the repo root; npm commands run from `web/`.
